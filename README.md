# 🔐 Gerador de Senhas em Python

Aplicação simples que gera senhas aleatórias utilizando Python.

## 📌 Funcionalidades

- Geração de senhas seguras
- Escolha do tamanho da senha

## 🚀 Como executar

Execute:

```
python main.py
```

## 🛠 Tecnologias

- Python
- Biblioteca random
